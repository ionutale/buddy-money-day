# Work → save → buy → play; care is rewarded, never priced

v1 modeled feeding Buddy as a skippable cost: skip it and you keep a Coin, but Buddy goes droopy. Playtesting showed the lesson that rehearses — "save instead of feeding the animal" — is the wrong one at any age, and the parent asked instead for a Store of priced toys bought with Coins earned through chores.

The v2 loop is **work → save → buy → play**. Each Money Day runs three paid Helping Tasks — Tidy the toys, Water the tree, Feed the bear — once each, in any order, so the daily cap teaches patience; then the Store, where the big button saves the remainder toward the Dream toy while buying a toy stays a deliberate second action (ADR-0002 still holds). Feeding is a paid task like tidying and watering, so care is never a trade-off. Every purchased toy unlocks real play in My Toys, and the dream list cycles — once every Dream toy is owned the pedestal offers the next, then starts over — so the loop never dead-ends.

ADR-0003's never-shame principle still holds; its droop example is retired, and no state in the game is ever sad. Slice 1 ships the ball's keepy-uppy game and the wagon and teddy Dreams (the wagon celebrates now; its pull-around game follows in slice 2); slice 2 adds the remaining toys and games, each shipped with its toy.
