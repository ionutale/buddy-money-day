# Consequences are gentle and always fixable

Needs-vs-wants has teeth only if skipping Buddy's food is visible: Buddy goes droopy with a rumbly tummy. But at 4, guilt and permanent loss teach fear rather than judgment, so no state in the game is ever lost for good — Buddy can be fed on any later Money Day, the Goal keeps its progress, and nothing escalates. A skipping child simply sees the natural, repairable result and gets the same warm ending.
