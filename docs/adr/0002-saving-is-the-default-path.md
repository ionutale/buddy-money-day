# Saving is the default path; both choices praised

At the Shelf, leftover Coins flow into the Save Jar unless the child deliberately acts to spend (the big primary action saves; the Temptation is a smaller, deliberate second action), and buying the Temptation triggers celebration, not reproach. The rationale is research-backed: defaults move kindergarteners toward waiting by ~20 percentage points, and 4-year-olds learn from choices only when both outcomes are safe. The goal is a child who chooses consciously — not one who never spends.
